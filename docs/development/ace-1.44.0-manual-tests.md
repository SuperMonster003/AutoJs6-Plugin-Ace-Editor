# Ace 1.44.0 手测指南 (附录 B / C 与视觉验收)

本文把 `Roadmap-Ace-1.44.0.md` 附录 B (移动端交互), 附录 C (输入法) 以及 A3 / A5 中只能目视验收的条目展开为可逐项执行的
步骤. 每项给出前置条件, 操作, 期望结果和 1.4.12 的实测参照, 结论记为 "通过 / P1 / P2 / P3" (见第 2 节), 汇总后写回路线图
(A8-4, G-A2, G-A3, G-A5-3, G-A5-7).

### 1.4 常用操作

- 冷启动宿主: 在最近任务中划掉 AutoJs6 (或 系统设置 > 应用 > AutoJs6 > 强行停止), 再重新打开文件.
- 编辑器主题 / 夜间模式: 宿主设置中的 "编辑器主题" 与 "夜间模式". 视觉项需在亮色与暗色下各看一次.
- 自动换行: 宿主编辑器设置中的 "自动换行" (V2, V10 用).
- 双指缩放: 宿主编辑器设置 "手势缩放" 应为 "更改字体大小" (B12, B13 用).
- 显式补全: 长按快捷栏上的 TAB 键 (等同 Ctrl-Space); 快捷栏还提供 ESC 与方向键.

## 2. 记录与分级

每项记录 "通过 / P1 / P2 / P3", 不通过时附一句现象. 出现问题时请尽量:

1. 截图或录屏 (Xperia 可用电源键 + 音量下截图);
2. 在问题出现后立即用编辑器菜单 "更多 > 复制 Ace 诊断信息" 复制诊断文本, 连同条目编号发给我
   (诊断中的 `runtimeEventHistory` 记录了最近的运行期事件, 附录 C 要求其中没有非预期的 `imeTextInputSelectionDropped`);
3. 也可以只告诉我条目编号与时间, 我用 adb 读取当时的日志.

| 等级 | 含义 | 处理 |
|---|---|---|
| P1 | 崩溃, 卡死 (ANR), 文本被改错或丢失, 输入法输入错误字符, 或与 1.4.12 行为相反且影响日常编辑 (如单击不能放置光标, 拖拽选不中) | 阻断合并 (合并标准要求 P1 为 0) |
| P2 | 功能可用但明显异常: 错位, 闪烁, 需要重复操作才生效, 视觉明显错误 | 合并前修复 |
| P3 | 轻微的视觉差异, 主观手感差异 | 记录, 可后续处理 |

需要与旧版逐项对比手感时告诉我: 我可以在约 1 分钟内把插件换成 1.4.12 构建 (`build/ace-perf/apk-a0/`), 对比后再换回.

本指南初版把 1.4.12 的五处既有表现列为 "不计为缺陷". 维护者手测后要求全部改进, 已在 A2-10 中实现 (2026-10-13), 下文对应
条目的期望已改为新行为:

- 慢点 (按住 100 至 500 ms 再抬手) 现在也移动光标 (B19).
- 手指静止超过 40 ms 再抬手不再惯性滚动 (B8, B20).
- 点在光标上弹出 "粘贴 / 全选" 插入点工具条; 空白处长按放置光标并弹出它 (B21, B22).
- 点击行号栏不移动光标, 不弹软键盘, 不跳视图; 有诊断的行上只有点在诊断图标上才打开提示, 其余位置切换断点 (B2).
- 超长行的 "<click to see more...>" 按钮可用手指点击, 切换自动换行 (B18).

仍保留的旧表现: 光标模式拖动后手指回到起点附近, 后续移动会被忽略 (长按计时器句柄未清空, 见 README "行为规格").

## 3. 附录 B · 移动端交互

除注明外使用 `01-touch.js`, 默认开关. "1.4.12 参照" 为 A0-6 在本机 (XQ-AT72) 的自动实测.

### B1 单击文本

- 操作: 在某个单词中间快速轻点 (正常点击, 100 ms 内抬起).
- 期望: 光标移到点击处 (标题栏的 "行:列" 随之变化), 软键盘弹出. 只读文档不弹出键盘 (可选: 打开宿主的示例脚本验证).
- 1.4.12 参照: 光标到点击位置, 请求软键盘.

### B2 单击行号栏

- 操作: (a) 光标放在远处 (如第 38 行), 软键盘收起和弹出时各做一次: 点击第 5 行的行号 (行号数字或其左侧都可以);
  (b) 点击第 6 行的折叠箭头, 再点击折叠后的占位符 (正文中的 "<->" 或省略标记); (c) 在 `02-visual.js` 中点击第 20 行
  行号栏左端的错误图标, 再点击该行的行号数字; (d) 在行号栏上下拖动.
- 期望: (a) 该行出现 / 取消断点红点; 光标不动, 软键盘不弹出, 视图不跳转 (A2-10); (b) 第 6-217 行折叠, 点击占位符后
  展开 (A3-5); (c) 点图标弹出该行的诊断提示 (光标会移到该行, 这是显示诊断提示的方式), 点行号数字切换该行的断点 (A2-10);
  (d) 与在正文中拖动一样滚动和惯性, 不切换断点.
- 1.4.12 参照: 光标到该行行首, 断点 / 折叠 / 诊断由行号栏的鼠标事件处理.
- 首轮手测 (2026-10-13): (a) 软键盘收起时点行号, 键盘弹出且视图跳回光标所在行 (缺陷, 已在 A2-10 修复); (b), (c) 正常.

### B3 双击

- 操作: 在同一个单词上快速点两下 (两次间隔 300 ms 内, 第二下与第一下相距约 1 行以内).
- 期望: 选中该单词, 选择工具条 (复制 / 粘贴 / 全选等) 出现; 光标落在选区中离手指较近的一端 (分别点单词前半与后半验证;
  正中间时落在末尾).
- 1.4.12 参照: 选中 "beta", 工具条出现. 1.4.12 的光标总在末尾 (判断写反), 首轮手测同样如此, 已在 A2-10 修复.
- 补充 (2026-10-14): 键盘显示时双击选词, 随后收起键盘 (返回手势), 偶发选中的单词被删除. 已修复 (A2-10 第 16 项, 构建 241).
  复测: 键盘显示时在几个单词上反复双击, 每次随后收起键盘, 单词都不消失, 撤销历史中没有多余记录.

### B4 长按 (无选区)

- 操作: 在单词上按住约 0.5 s 不动.
- 期望: 选中该单词, 有一次震动反馈, 工具条出现.
- 1.4.12 参照: 选中 "beta", 工具条出现.

### B5 在已有选区内长按

- 操作: 先用 B3 / B4 选中一段文字 (最好跨几个单词), 再在选区内部长按.
- 期望: 选区不变, 工具条出现 (可能先消失再出现).
- 1.4.12 参照: 选区 6:6-6:20 不变, 工具条出现.

### B6 拖动光标

- 操作: 单击放置光标, 然后按在光标上 (稍偏下更容易命中) 向右下慢慢拖动, 拖到靠近屏幕右边缘与下边缘处停留片刻再抬手.
  再开启放大镜 (开关脚本) 重复一次.
- 期望: 光标随手指移动, 页面不跟着滚动, 不产生选区; 光标接近可视区域边缘时视口自动滚动, 并在光标两侧多露出约 5 列;
  抬手后不出现工具条 (无选区). 放大镜开启时: 拖动中手指上方 (靠近顶部时为下方) 出现放大框, 显示光标所在行及上下各一行,
  中间有光标竖线, 其位置与编辑器中的光标一致 (落在两个字符之间), 文字随拖动更新; 抬手后放大框消失. 在 `02-visual.js`
  第 12 行来回拖过 `item` 等标识符时移动连贯, 不在标识符前停顿 (抬手约 0.2 s 后才出现同名符号高亮).
- 1.4.12 参照: 光标到 9:30, 抬手后无工具条. (1.4.12 的放大镜从未启用, 无参照.)
- 首轮手测 (2026-10-13): 放大镜关闭时正常; 开启时光标竖线偏离约半个字符, 拖过标识符前会卡顿一下. 两处已在 A2-10 修复
  (放大镜多算了文本层内边距; 拖动中暂停同名符号高亮请求).

### B7 拖动选区锚点

- 操作: 长按选中一个单词, 拖动光标端扩展到 2-3 行, 抬手; 然后按住选区的另一端 (锚点, 即不在光标处的那一端) 拖动.
  另试: 按住锚点后只移动很小的距离 (1 行以内) 再抬手.
- 期望: 锚点随手指移动, 选区相应扩展 / 收缩, 抬手后工具条出现; 离起点约 1.3 行以内的移动被忽略 (选区不变).
  两端都在手指附近时 (很短的选区) 拖动较近的一端. 放大镜开启时的表现同 B6, 放大框中同时显示选区底色.
- 1.4.12 参照: 锚点到 10:2, 工具条出现; 只拖 1 行时锚点不动.

### B8 空白处慢速拖动 (滚动)

- 操作: 在文字上 (不在光标附近) 按住后缓慢上下拖动, 拖到文档末尾继续向上拖.
- 期望: 手指离开起点约 1.3 行后页面随手指滚动, 光标不动; 可越过文档末尾约 200 px; 不触发长按选词 (移动后计时取消);
  停住后再抬手, 页面不再继续滚动 (A2-10).
- 1.4.12 参照: 随手指滚动; 停住后抬手又滚动了约 15 px.

### B9 快速滑动 (惯性)

- 操作: 快速上滑后抬手; 再先用 B3 选中一个单词, 然后滑动.
- 期望: 抬手后继续滚动并逐渐减速停止, 手感与系统列表接近; 有选区时, 滑动开始工具条消失, 停止后约 0.2 s 工具条重新出现.
- 1.4.12 参照: 继续滚动 (80 行文档中 528 -> 671 px), 结束后检查选区并重新显示工具条.

### B10 惯性中再次触摸

- 操作: 做一次 B9 的快速滑动, 在滚动尚未停止时按住屏幕.
- 期望: 滚动立即停止. (按下后的抬手按普通触摸处理: 快速抬手会放置光标, 按住 0.5 s 会选词, 均属正常.)
- 1.4.12 参照: 触摸后位移 0.

### B11 补全弹窗打开时触摸弹窗

- 文件: `06-ime.js`.
- 操作: 在第 6 行输入 `console.`, 等成员补全弹窗出现; 在弹窗内上下滑动列表; 若选中项旁出现文档提示, 在提示内滑动;
  最后点击一个候选.
- 期望: 列表随手指滚动, 编辑器正文不滚动, 光标不动; 文档提示可滚动; 点击候选后插入该项, 弹窗关闭 (A3-3).
  文档提示不遮挡补全弹窗: 旁边放不下时出现在弹窗下方 (弹窗在光标上方时为上方), 都放不下时不显示 (A2-10).
  切换编辑器主题后再打开弹窗, 配色随主题变化.
- 1.4.12 参照: 未自动化, 无参照.
- 首轮手测 (2026-10-13): 含 "declare" 的文档提示遮挡了补全弹窗 (已在 A2-10 修复). 另发现宿主设置页暗色主题下, "Editor theme"
  对话框右上 "更多" 菜单亮底亮字无法辨识: 属宿主通用对话框组件, 已另立任务, 不计入本清单.

### B12 双指按下

- 操作: 一指按住单词 (未满 0.5 s), 紧接着第二指落下, 做缩放.
- 期望: 不触发长按选词与震动, 工具条不出现 (若之前有则消失), 进入双指缩放.
- 1.4.12 参照: 宿主记录长按反馈被抑制, ActionMode 因双指缩放被抑制.

### B13 双指缩放

- 操作: 两指在某一行附近张开放大, 再捏合缩小, 反复几次; 抬手.
- 期望: 字号随手势变化 (约 14 至 42 sp 之间), 两指中点附近的文字在缩放后仍大致留在两指中点附近 (焦点不漂移, A3-7),
  抬手后光标不跳动, 不产生选区.
- 1.4.12 参照: 字号 14 -> 42 sp; 焦点漂移未自动校验.

### B14 旋转屏幕 / 软键盘弹出后重复 B6, B7

- 操作: 打开系统自动旋转, 横屏后重复 B6, B7; 回到竖屏, 单击使软键盘弹出后再重复 B6, B7 (放大镜开 / 关各一次).
- 期望: 拖拽命中与光标位置准确, 不偏移一行或数列; 放大框位置与内容正确.
- 1.4.12 参照: 未自动化.

### B15 点击他处清除选区

- 操作: B3 选中单词并出现工具条后, 点击另一行的文字.
- 期望: 选区清空, 工具条消失, 光标到点击处.
- 1.4.12 参照: 选区清空, 工具条消失.

### B16 拖动光标后直接输入

- 操作: B6 拖动光标 (无选区) 并抬手后, 立即用软键盘输入几个字符.
- 期望: 字符插入在新光标处, 没有工具条闪现. (1.4.12 在此状态下会发出 "无选区 ActionMode", 宿主本就不显示.)
- 1.4.12 参照: 未自动化.

### B17 长按后切到后台再返回

- 操作: (a) B4 长按选词, 工具条出现后按 Home 键, 稍后从最近任务返回; (b) 开启放大镜, 拖动光标时 (手指不抬起)
  用另一只手按电源键锁屏, 解锁后返回.
- 期望: 返回后没有残留的工具条或放大框 (选区可以保留, 再次单击或长按行为正常).
- 1.4.12 参照: 未自动化.

### B18 超长行安全模式下重复 B1-B9

- 文件: `04-long-line.js`.
- 操作: 打开文件, 记下大致的打开耗时; 横向滑动查看第 6 行; 在第 9 行以下重复 B1-B9.
- 期望: 打开过程无卡死 (ANR); 第 6 行在 4096 字符处截断并显示 "<click to see more...>" 按钮; 安全模式下语言服务关闭,
