# Ace 1.44.0 手测清单 · 百度输入法 (附录 C)

本清单是 `ace-1.44.0-manual-tests.md` 附录 C 的百度输入法版本, 可单独使用. Gboard 的附录 C 已在 2026-10-13 / 14 完成并通过;
本轮只用百度输入法, 结果用于收口 G-A3, A8-4 (附录 C 需要一款中文输入法) 与 G-A5-7 (ghost text 的输入法门).
分级标准与主指南第 2 节相同: 通过 / P1 / P2 / P3, P1 为文本被改错或丢失, 输入错误字符, 崩溃或卡死.

## 1. 准备

| 项 | 内容 |
|---|---|
| 设备 | XQ-AT72 (QV710AF65F) |
| 宿主 / 插件 | 手机上现有的宿主; Ace 插件构建号不低于 243 (编辑器菜单 "更多 > 复制 Ace 诊断信息" 中可见); 第 4 节复测需要不低于 249 |
| 输入法 | 百度输入法 OEM 版 (`com.baidu.input_oem`, 已安装并启用) |
| 测试文件 | `/sdcard/Scripts/ace-1.44.0-manual/06-ime.js` (C1-C5, C7, C8, C11, C12), `05-crlf.js` (C6) |

1. 切换输入法: 打开 `06-ime.js`, 点任一空行弹出键盘, 点导航栏右下角的键盘图标 (或长按空格键) 选 "百度输入法".
2. 百度输入法用 26 键全键盘. 如果设置中有 "空格键滑动移动光标", "双击空格输入句号" 之类的选项, 保持默认, 记下当时的状态.
3. 每做完一项, 如文件被改动, 用撤销恢复或不保存直接关闭; C6 需要保存, 做完告诉我.
4. 全部结束后复制一次 Ace 诊断信息 (编辑器菜单 "更多 > 复制 Ace 诊断信息") 发给我, 我核对 `runtimeEventHistory` 中没有非预期的
   `imeTextInputSelectionDropped`. 也可以只告诉我出问题的条目与大致时间, 我用 adb 读取当时的日志.
5. 测完把输入法切回 Gboard (可选).

## 2. 条目

### C1 英文连续输入与联想

- 操作: 切到英文模式, 在第 6 行输入 `the quick brown fox jumps over the lazy dog`, 中途从候选栏点选一两次联想词.
- 期望: 无重复或丢失的字符, 光标始终在刚输入的文字之后, 联想替换后的单词正确.

### C2 连续两次空格

- 操作: 英文模式下输入一个单词后连按两次空格.
- 期望: 得到两个空格, 不是 ". " (若百度输入法本身开启了 "双击空格输入句号" 并因此插入句号, 记为输入法设置所致, 注明即可).

### C3 跨行退格

- 操作: 光标放在第 12 行行尾, 连续按退格 (再试一次长按退格) 直到删到第 9 行行首; 撤销恢复后, 选中第 9-12 行按一次退格, 再撤销.
- 期望: 删除的内容与屏幕上看到的一致, 行正确合并, 没有残留字符或 "幽灵" 文字; 选中多行退格删掉整个选区; 撤销能完整恢复原文,
  撤销后选区范围正常.

### C4 光标移动

- 操作: (a) 打开百度输入法工具栏中的 "编辑" / "光标" 面板 (名称因版本而异): 在单词中间用左右上下键移动光标, 在长行 (第 2 行)
  中按 "行首" / "行尾" (若有), 用面板的 "选择" 扩展选区后再取消, 按 "全选"; (b) 若支持空格键滑动移动光标, 在空格键上左右滑动,
  越过行尾与行首.
- 期望: 左右每按一次移动一个字符 (单词中间也一样), 上下移到上 / 下一行并尽量保持列; 行首 / 行尾到当前行两端, 长行横向滚动
  跟随光标; "选择" 时扩展选区, 取消后收为光标; "全选" 选中整篇并出现宿主的选择工具条. 空格滑动时光标连续移动, 越过行尾接到
  下一行行首, 越过行首接到上一行行尾. 全程不插入字符, 文档不变 (保存按钮保持灰色).

### C5 有选区时输入

- 操作: 双击选中一个单词, 直接输入英文 `xyz`; 撤销后再双击选中一个单词, 用拼音输入 "测试" 上屏.
- 期望: 选区被替换为 `xyz` / "测试", 其余文字不变.

### C6 粘贴多行文本 (CRLF 文档)

- 操作: 在 `06-ime.js` 中选中第 14-16 行并复制; 打开 `05-crlf.js`, 在 "Paste here" 下一行用百度输入法的剪贴板 (工具栏中的剪贴板
  面板) 粘贴刚才的内容; 保存. 告诉我已保存.
- 期望: 粘贴内容与复制的三行一致; 保存后整个文件仍全部是 CRLF 换行 (我用 adb 检查文件字节).

### C7 中文拼音组合输入

- 操作: 拼音输入 "你好世界, 这是中文注释", 中途至少一次翻页选择候选, 至少一次用候选栏的整句候选上屏.
- 期望: 组合期间编辑器中显示带下划线的拼音或预选文字, 补全弹窗不出现或不乱跳; 上屏后字符正确, 无重复, 光标在文字之后.

### C8 拼音组合中途切换到英文

- 操作: 输入拼音 `zhong` (尚未上屏), 点百度输入法的中 / 英切换键, 再继续输入英文 `abc`.
- 期望: 组合文字按输入法的行为上屏或清除, 编辑器中不残留未完成的组合文字, 无重复字符.

### C9 符号与表情 (百度输入法补充项)

- 操作: 从百度输入法的符号面板输入 `( ) { } ; "`, 再输入一个表情符号 (如 😀), 然后按一次退格.
- 期望: 符号按原样插入 (编辑器自动补全括号或引号属于既有行为, 不算缺陷); 表情作为一个字符插入, 一次退格整个删掉, 不留下乱码.

### C10 语音输入 (可选)

- 操作: 若百度输入法有语音键, 说一句中文.
- 期望: 识别出的文字正确插入, 无重复. 没有语音键或无网络时跳过, 注明即可.

### C11 ghost text 预览下的输入 (G-A5-7)

- 前置: 在 AutoJs6 文件页运行 `00-toggles.js`, 选 "勾选要开启的项", 勾选 "补全 ghost text 预览", 确定并保存; 关闭再重新打开
  `06-ime.js`.
- 操作: 在空行依次输入下面的样例 (约 200 字符; 代码用英文模式, 中文注释用拼音):

  ```js
  function greet(name) {
      const message = "hello " + name;
      console.log(message.toUpperCase());
      return message.length;
  }
  // 你好世界, 这是一段中文注释
  greet("world");
  ```

  补全弹窗出现时观察光标后的灰色预览; 按快捷栏 TAB 接受一次, 按 ESC 取消一次.
- 期望: 预览显示首个候选的剩余部分, 继续输入时随之更新; 拼音组合期间不显示预览; TAB 接受的正是预览的内容; ESC 清除预览与
  弹窗; 全程无重复字符, 光标不跳动; 浮动窗口 (补全弹窗, 说明框, 参数提示) 不遮挡光标所在行.
- 结束后: 运行 `00-toggles.js`, 选 "全部恢复默认值" (ghost text 默认关闭), 关闭再重新打开文件.

### C12 补全弹窗打开时继续输入

- 操作: 英文模式下在空行输入 `cons`, 弹窗出现后继续输入 `ole`, 再输入 `.`, 再输入 `lo`.
- 期望: 候选随输入过滤 (最终首项为 `console`); 输入点后弹窗切换为成员补全 (如 `log`, `warn`), 输入 `lo` 后过滤为 `log` 等.
  百度输入法在英文模式下可能把 `cons` 作为组合 (带下划线) 处理, 只要上屏结果正确, 弹窗不乱跳即可.
