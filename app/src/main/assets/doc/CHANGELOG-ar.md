# v1.1.0

###### 2026/07/27

* `ميزة` تم الاحتفاظ بالتصريحات المصدرية الكاملة وإضافة مجموعات تصريحات LSP قابلة للاختيار في AutoJs6: تظل `core` مفعلة دائما, بينما تكون `android` و`libraries` و`resources` و`main-app` معطلة افتراضيا; يؤدي اختيار `libraries` أيضا إلى تفعيل `android`, ويؤدي اختيار `main-app` أيضا إلى تفعيل `android` و`libraries` و`resources`
* `ميزة` تمت إضافة مهمة Gradle المسماة `:app:generateAutoJs6LspDeclarations` للتحقق من التصريحات وإنشاء مجموعات LSP الخمس وملف manifest الخاص بها; يستدعيها دمج الأصول المعتاد تلقائيا ويمكن للبرامج النصية الخارجية استدعاؤها مباشرة
* `تبعية` تمت ترقية خدمة لغة TypeScript المضمنة وتصريحات المكتبة القياسية من `4.2.4` إلى `6.0.3`

# v1.0.0

###### 2026/07/21

* `ميزة` تمت إضافة مكون إضافي مستقل لمحرر Ace بمعرف المكون `ace-editor` والمحرك `editor` والمتغير `ace`

* `ميزة` تمت إضافة خدمات لغات JavaScript/TypeScript المضمنة وتصريحات الأنواع الخاصة بـ AutoJs6 لتوفير الإكمال وhover وdiagnostics وsignature help, مع توفير syntax diagnostics فقط لملفات JSON
* `ميزة` تمت إضافة مزامنة النص التزايدية والحفاظ على CRLF والتحميل المجزأ للنصوص الكبيرة ووضع خفيف للأسطر الطويلة جدا وتكييف IME

* `ميزة` تمت إضافة مراقبة سلامة بيئة تشغيل WebView واكتشاف نبضات الاتصال وإشعارات الرجوع إلى محرر المضيف الأصلي
* `ميزة` تمت إضافة بيانات المكون الإضافي ومحتوى README وCHANGELOG المترجم إلى الإسبانية والفرنسية والروسية والعربية واليابانية والكورية والإنجليزية والصينية المبسطة والصينية التقليدية في هونغ كونغ والصينية التقليدية في تايوان
